# CMC Pathway Typography Guide — Moved

Typography, color, spacing, mobile readability, navigation, forms, and component rules now live together in the canonical **[CMC Pathway Style Guide](STYLE-GUIDE.md)**.

Use that document as the **single source of truth**. In particular, refer to:

- **Section 2 — Canonical tokens:** Montserrat, the approved type roles (10–80px), reading widths, spacing, and color contrast.
- **Section 3 — Component language:** text hierarchy for page headers, cards, forms, controls, progress, and status.
- **Section 4 — Responsive and accessible behavior:** mobile sizes, tap targets, zoom, and keyboard focus.
- **Section 6 — Source-of-truth workflow:** token usage and tests required for changes.

This forwarding file is retained so existing repository links keep working. **Do not maintain independent typography rules here**; update `STYLE-GUIDE.md` instead.
